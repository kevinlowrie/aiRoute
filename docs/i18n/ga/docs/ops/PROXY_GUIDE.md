## Cén Fáth a Úsáid Proxies?

Cuireann go leor soláthróirí AI srian ar rochtain de réir réigiúin gheografacha. Forbróirí i** An Rúis, an tSín, an Iaráin, Cúba, an Tuirc** , agus tagann earráidí i dtíortha eile ar nós:

```
unsupported_country_region_territory
```

Fiú taobh amuigh de na réigiúin bhac, tá seachvótálaithe úsáideach le haghaidh:

| Úsáid Cás                   | Cur síos                                                                     |
| --------------------------- | ---------------------------------------------------------------------------- |
| **Seachbhóthar geografach** | Rochtain OpenAI, Anthropic, Codex, Copilot ó thíortha a bhfuil bac orthu     |
| **IP rothlú**               | Déan iarratais a dháileadh thar iolrach IPs chun teorannú rátaí a sheachaint |
| **Príobháideacht**          | Folaigh do IP fíor ó sholáthraithe in aghaidh an tsrutha                     |
| **Comhlíonadh**             | Bealach tráchta trí dhlínsí sonracha                                         |
| **Tástáil**                 | Insamhail iarratais ó réigiúin éagsúla                                       |

## Staid seachfhreastalaí réamhshocraithe do chuntais nua

I** Socruithe → Proxy → Cumraíocht dhomhanda** , úsáid** Cumasaigh seachfhreastalaí de réir réamhshocraithe le haghaidh naisc nua** chun staid tosaigh seachfhreastalaí na gcuntas soláthraithe nua-bhreise a roghnú.

Rialaíonn an socrú nua staid seachfhreastalaí tosaigh na gcuntas soláthraithe nua-bhreise. Ní athraíonn sé cuntais reatha ná ní athraítear an lasc seachfhreastalaí domhanda. Caomhnaíonn a luach tosaigh an t-iompar roimhe seo. Múch é uair amháin chun cuntais sa todhchaí a chruthú a bhfuil seachfhreastalaí díchumasaithe orthu de réir réamhshocraithe.

Stóráiltear an rogha mar `defaultNewConnectionProxyEnabled` trí na Socruithe reatha API. Mainneachtainí sé `true` nuair riamh shábháil. Tagann sábháil `false` i bhfeidhm do chuntais nua ina dhiaidh sin gan atosú. glacann `POST /api/providers` `proxyEnabled` boolean dian roghnach; bíonn tosaíocht ag `true` nó `false` sainráite thar réamhshocrú an chruthaithe. Caomhnaíonn easnamh ar chuntas dúblach nó OAuth reconnect staid stóráilte an chuntais sin. Is féidir cuntais aonair a chumasú nó a dhíchumasú fós ina dhiaidh sin.

Úsáideann aistrithe soláthraithe roghnacha réamhshocrú na suiteála sprice le haghaidh cuntas nua agus caomhnaítear an beartas cinn scríbe nuair a chuirtear cuntais nua in ionad na gcuntas atá ann cheana. Ní réimsí aistrithe iniompartha iad scoránaigh seachfhreastalaí. Coinníonn athchóiriú cúltaca iomlán agus ascnamh JSON/SQL stairiúil a shéimeantaic athchóirithe reatha, lena n-áirítear luachanna cuntas sábháilte agus mainneachtainí scéimre oidhreachta; is féidir an rogha seo a chur ar ais le hathchóiriú iomlán na socruithe.

Ní dhéanann an rogha seo seachfhreastalaí a shannadh ná a shuíomh go bhfuil ceann sláintiúil nó in úsáid. Braitheann ródú iarbhír fós ar an lasc seachfhreastalaí domhanda agus ar chumraíocht seachfhreastalaí is infheidhme. Tá soláthraithe sintéiseacha gan cuntas leanúnach, trácht OAuth roimh chruthú cuntais, seachvótálaithe environment/system, agus líonrú na n-aisíní seachtracha lasmuigh dá raon feidhme.

## Córas Seachfhreastalaí 4-Leibhéil

tacaíonn OmniRoute le cumraíocht seachfhreastalaí ag** ceithre scóip neamhspleácha** , réitithe in ord tosaíochta:

```
Priority Resolution Order (highest → lowest):

  1. 🔵 Account/Connection Proxy  →  per API key / OAuth connection
  2. 🟡 Provider Proxy            →  per provider (e.g., all OpenAI traffic)
  3. 🟠 Combo Proxy               →  per combo/routing configuration
  4. 🟢 Global Proxy              →  all traffic, all providers
```

### Conas a Oibríonn Rún

Nuair a sheolann OmniRoute iarratas chuig soláthraí in aghaidh an tsrutha, glaonn sé `resolveProxyForConnectionFromRegistry()` a sheiceálann gach leibhéal in ord:

1. **Leibhéal cuntais** — An bhfuil seachfhreastalaí sannta don nasc sonrach seo ID?
2. **Soláthraí-leibhéal** — An bhfuil seachfhreastalaí sannta don soláthraí seo (m.sh., `openai`)?
3. **Leibhéal domhanda** — An bhfuil seachfhreastalaí domhanda cumraithe?
4. **Gan seachfhreastalaí** — Ceangal díreach leis an soláthraí.

Bhuaigh an chéad chluiche. Ciallaíonn sé seo gur féidir leat seachfhreastalaí domhanda a shocrú mar chúltaca ach é a shárú le haghaidh soláthraithe nó naisc ar leith.

## Clárlann Seachfhreastalaí (CRUD)

Is tábla SQLite (`proxy_registry`) í an chlár seachfhreastalaí a stórálann do sheachvótálaithe go léir. Tá:

| Réimse     | Cineál     | Cur síos                               |
| ---------- | ---------- | -------------------------------------- |
| `id`       | UUID       | Aitheantóir uathúil                    |
| `name`     | Teaghrán   | Lipéad inléite ag an duine             |
| `type`     | Teaghrán   | Prótacal: `http`, `https`, `socks5`    |
| `host`     | Teaghrán   | Óstainm seachfhreastalaí nó IP         |
| `port`     | Slánuimhir | Uimhir phoirt                          |
| `username` | Teaghrán   | Ainm úsáideora Údar (criptithe ar fos) |
| `password` | Teaghrán   | Pasfhocal Údar (criptithe ar fos)      |
| `region`   | Teaghrán   | Lipéad réigiún geografach              |
| `notes`    | Teaghrán   | Nótaí téacs saor in aisce,             |
| `status`   | Teaghrán   | `active` nó `inactive`                 |
| `source`   | Teaghrán   | `manual` nó `oneproxy`                 |

### Proxy a Chruthú

**Tríd an Deais:**

1. Téigh go dtí** Socruithe → Proxy**
2. Cliceáil** Cuir Seachfhreastalaí leis**
3. Líon isteach an cineál, an t-óstach, an port, agus dintiúir an údair roghnach
4. Sábháil

**Trí API:**

```bash
curl -X POST http://localhost:20128/api/v1/management/proxies \
  -H "Content-Type: application/json" \
  -d '{
    "name": "US Proxy",
    "type": "http",
    "host": "proxy.example.com",
    "port": 8080,
    "username": "user",
    "password": "pass",
    "region": "US"
  }'
```

### Proxy á nuashonrú

```bash
curl -X PATCH http://localhost:20128/api/v1/management/proxies \
  -H "Content-Type: application/json" \
  -d '{
    "id": "proxy-uuid-here",
    "host": "new-proxy.example.com",
    "port": 9090
  }'
```

> **Nóta:** Coinnítear dintiúir mura seolann tú earraí athsholáthair nach bhfuil folamh go sainráite. Coimeádfar na luachanna stóráilte má sheoltar teaghráin fholmha le haghaidh `username`/`password`.

### Seachfhreastalaí a scriosadh

```bash
# Fails if proxy is assigned to any scope
curl -X DELETE "http://localhost:20128/api/v1/management/proxies?id=proxy-uuid"

# Force delete (removes assignments too)
curl -X DELETE "http://localhost:20128/api/v1/management/proxies?id=proxy-uuid&force=1"
```

### Proxies Liostú

```bash
curl "http://localhost:20128/api/v1/management/proxies?limit=50&offset=0"
```

### Proxies a Shannadh do Scópaí

```bash
# Assign to global scope
curl -X PUT http://localhost:20128/api/settings/proxy \
  -H "Content-Type: application/json" \
  -d '{"level": "global", "proxy": {"type":"http","host":"proxy.example.com","port":8080}}'

# Assign to a specific provider
curl -X PUT http://localhost:20128/api/settings/proxy \
  -H "Content-Type: application/json" \
  -d '{"level": "provider", "id": "openai", "proxy": {"type":"socks5","host":"socks.example.com","port":1080}}'

# Assign to a specific connection/key
curl -X PUT http://localhost:20128/api/settings/proxy \
  -H "Content-Type: application/json" \
  -d '{"level": "key", "id": "connection-uuid", "proxy": {"type":"http","host":"key-proxy.com","port":3128}}'
```

### Seachfhreastalaí Éifeachtach a Réiteach

Seiceáil cé acu seachfhreastalaí a d'úsáidfí do nasc ar leith:

```bash
curl "http://localhost:20128/api/settings/proxy?resolve=connection-uuid"
```

Filleann sé an seachfhreastalaí réitithe lena leibhéal (`account`, `provider`, nó `global`) agus foinse.

### Tasc Bulc

Sann seachfhreastalaí amháin do sholáthraí iolracha nó naisc ag an am céanna:

```bash
curl -X POST http://localhost:20128/api/v1/management/proxies/bulk-assign \
  -H "Content-Type: application/json" \
  -d '{
    "scope": "provider",
    "scopeIds": ["openai", "anthropic", "codex"],
    "proxyId": "proxy-uuid"
  }'
```

### Import/Export

Proxies san áireamh sa**Backup/Restore** córas. Nuair a easpórtálann tú do chumraíocht OmniRoute :

1. Téigh go dtí** Socruithe Painéal → →**
2. Cliceáil** Easpórtáil** — proxy registry agus tascanna san áireamh
3. Chun a chur ar ais, cliceáil** Iompórtáil** agus an comhad cúltaca a uaslódáil

Tacaíonn an chlár seachfhreastalaí freisin** upsert ag port + óstach** — má iompórtálann tú seachfhreastalaí atá ann cheana féin (an t-óstach céanna agus an port céanna), déanann sé nuashonrú in ionad dúblach a chruthú.

### Imirce Oidhreacht

Má chumraigh tú seachvótálaithe i leagan níos sine (réamhchlárú), aistríonn OmniRoute iad go huathoibríoch:

```
Legacy key_value store → proxy_registry + proxy_assignments
```

Tarlaíonn sé seo uair amháin ar an gcéad tosaithe tar éis uasghrádú. Bain úsáid as `migrateLegacyProxyConfigToRegistry({ force: true })` a athreáchtáil.

## Margadh seachfhreastalaí 1 seachfhreastalaí

> 🆕** Arna chur suas ag [@oyi77](https://github.com/oyi77)** — PR [#1847](https://github.com/diegosouzapw/OmniRoute/pull/1847) ( Issue [#1788](https://github.com/diegosouzapw/OmniRoute/issues/1788) )

chomhtháthaíonn OmniRoute leis an** [1seachfhreastalaí](https://1proxy-api.aitradepulse.com)** ardán pobail chun rochtain a sholáthar ar** na céadta seachvótálaithe saor in aisce, deimhnithe** ó ar fud an domhain. Tá sé seo foirfe d'úsáideoirí nach bhfuil a mbonneagar seachfhreastalaí féin acu.

### Conas a Oibríonn sé

```
┌─────────────┐     Sync      ┌─────────────────┐    Rotate     ┌──────────┐
│  1proxy API │ ────────────▶ │  proxy_registry  │ ────────────▶ │ Provider │
│  (external) │   up to 500   │  source=oneproxy │  by quality   │   API    │
└─────────────┘    proxies    └─────────────────┘               └──────────┘
```

1. **Sioncrónaigh** Faigheann — OmniRoute seachvótálaithe ón 1proxy API
2. **Stóráil** — Déantar seachfhreastalaí a shábháil sa tábla `proxy_registry` céanna le `source = 'oneproxy'`
3. **Scagaire** — Scag de réir prótacail, tíre, scór cáilíochta
4. **Rothlaigh** — Roghnaigh an seachfhreastalaí is fearr ag baint úsáide as straitéisí cáilíochta, randamacha nó seicheamhacha
5. **Díghrádaigh go huathoibríoch** — Laghdaítear scór cáilíochta na seachvótálaithe ar theip orthu; faoi bhun na tairsí tá → marcáilte neamhghníomhach

### Proxies a shioncronú

**Tríd an Deais:**

1. Téigh go dtí** Socruithe → 1proxy** cluaisín
2. Cliceáil** "Sioncronaigh Anois"**
3. Féach ar staitisticí: seachfhreastalaí iomlána, comhaireamh gníomhach, meánchaighdeán, miondealú de réir tíre

**Trí API:**

```bash
# Trigger sync
curl -X POST http://localhost:20128/api/settings/oneproxy \
  -H "Content-Type: application/json" \
  -d '{}'

# Response:
# { "success": true, "added": 127, "updated": 45, "failed": 2, "total": 172 }
```

### Proxies Scagtha

```bash
# Filter by protocol
curl "http://localhost:20128/api/settings/oneproxy?protocol=socks5"

# Filter by country

# Filter by minimum quality score
curl "http://localhost:20128/api/settings/oneproxy?minQuality=80"

# Combine filters
curl "http://localhost:20128/api/settings/oneproxy?protocol=http&countryCode=DE&minQuality=70"
```

## Seiceáil Sláinte Seachfhreastalaí (v3.8.16 +)

OmniRoute's** seachfhreastalaí tapa-teip** aimsíonn meicníocht (`src/lib/proxyHealth.ts`) seachvótálaithe marbh i < 2s trí sheiceáil thapa nasc TCP, ansin** caches an toradh** chun forchostais in aghaidh an iarratais a sheachaint.

### Conas a Oibríonn sé

```
Request ──▶ ProxyHealthCache.get(url)
             │
             ├─ Cache hit + fresh?  ──▶ return cached status
             │
             └─ Cache miss / stale?  ──▶ TCP connect to host:port
                                          (timeout: FAST_FAIL_TIMEOUT_MS)
                                          ──▶ cache for HEALTH_CACHE_TTL_MS
                                          ──▶ return result
```

Gan é seo, chuirfeadh seachfhreastalaí marbh bac ar gach iarratas ar an `PROXY_TIMEOUT_MS` iomlán (30idí réamhshocraithe) sula dteipfeadh air.

### Athróga Timpeallachta Tunable

| Athróg                       | Réamhshocrú | Cuspóir                                                   |
| ---------------------------- | ----------- | --------------------------------------------------------- |
| `PROXY_FAST_FAIL_TIMEOUT_MS` | `2000`      | teorainn ama ceangail TCP in aghaidh an tseiceáil sláinte |
| `PROXY_HEALTH_CACHE_TTL_MS`  | `30000`     | Cé chomh fada agus a dhéantar toradh sláinte a thaisceadh |

**Luachanna molta:**

| Cás                    | Teorainn ama mear-theip | Taisce TTL | Réasúnaíocht                                                                               |
| ---------------------- | ----------------------- | ---------- | ------------------------------------------------------------------------------------------ |
| Geata API ard-thréchur | 1500ms                  | 60000ms    | Ionsaitheach teip-tapa, taisce níos faide chun seiceálacha a laghdú                        |
| Nóid geo-dháilte       | 3000ms                  | 15000ms    | Teastaíonn níos mó ama ó líonraí níos moille; taisce níos giorra le haghaidh failover tapa |
| Dev / tástáil          | 1000ms                  | 10000ms    | Atriall tapa ar sheachvótálaithe áitiúla                                                   |
| Stealth / frith-bhrath | 2500ms                  | 45000ms    | Seachain iniúchadh tapa a d'fhéadfadh teorainneacha rátaí a spreagadh                      |

### Iniúchadh Sláinte Seachfhreastalaí

```ts
import { getAllProxyHealthStatuses, invalidateProxyHealth } from "omniroute/proxyHealth";

const statuses = getAllProxyHealthStatuses();
for (const s of statuses) {
  console.log(`${s.proxyUrl} → healthy=${s.healthy}, stale=${s.stale}`);
}

// Force re-check a specific proxy
invalidateProxyHealth("http://user:pass@203.0.113.7:8080");
```

Tá an bhratach `stale` `true` nuair a sháraigh an iontráil taisce `HEALTH_CACHE_TTL_MS` agus spreagfaidh an chéad iarratas eile seiceáil úr.

### Réamhshocrú Cineál Per-Proxy

Úsáideann an tseiceáil sláinte mainneachtainí ciallmhara bunaithe ar an scéim URL :

| Scéim                      | Port réamhshocraithe |
| -------------------------- | -------------------- |
| `http://`                  | 8080                 |
| `https://`                 | 443                  |
| `socks5://` / `socks5h://` | 1080                 |

Bíonn tosaíocht i gcónaí ag calafoirt saincheaptha sa URL (`http://host:9999`) ar réamhshocrú na scéime.

## Anailísíocht Seachfhreastalaí & Inbhraite

Rianaíonn OmniRoute úsáid in aghaidh an tseachfhreastalaí chun cabhrú le hoibreoirí patrúin ródaithe, spikes latency, agus teipeanna athfhillteacha a dhiagnóiseadh.

### Cad atá Rianaithe

Maidir le gach iarratas trí sheachvótálaí cumraithe, taifeadann OmniRoute :

| méadrach     | Cur síos                                                                  |
| ------------ | ------------------------------------------------------------------------- |
| `proxy_url`  | URL seachfhreastalaí iomlán (agus dintiúir an údair folaithe)             |
| `provider`   | Soláthraí in aghaidh an tsrutha ID (openai, antraipeach, etc.)            |
| `latency_ms` | Iomlán am turas cruinn lena n-áirítear croitheadh láimhe seachfhreastalaí |
| `connect_ms` | am ceangail TCP amháin                                                    |
| `status`     | HTTP cód stádais ó in aghaidh an tsrutha                                  |
| `error`      | Earráid sa rang má theip ar an iarratas                                   |
| `timestamp`  | ISO 8601 UTC                                                              |

### Rochtain ar na Sonraí

```bash
# Recent proxy events
curl -H "Authorization: Bearer $OMNIROUTE_KEY" \
  "http://localhost:20128/api/usage/proxy-logs?limit=100"
```

Is é `/api/usage/proxy-logs` an críochphointe fíor (féach `src/app/api/usage/proxy-logs/route.ts`). Tacaíonn an críochphointe seo le:

- `GET /api/usage/proxy-logs` — a aisghabháil logaí seachfhreastalaí
- `DELETE /api/usage/proxy-logs` — soiléir gach logaí seachfhreastalaí

Is féidir staitisticí comhiomlána a cheistiú go díreach ón tábla `proxy_logs` trí SQL más gá. Féadfaidh an painéal UI radhairc chomhiomlána a thairiscint.

### Patrúin Coiteann

**Braith seachfhreastalaí flapping** (malartacha idir success/failure):

```sql
SELECT proxy_url,
       COUNT(*) AS total,
       SUM(CASE WHEN status >= 500 THEN 1 ELSE 0 END) AS errors,
       ROUND(100.0 * SUM(CASE WHEN status >= 500 THEN 1 ELSE 0 END) / COUNT(*), 1) AS error_pct
FROM proxy_logs
WHERE timestamp > datetime('now', '-1 hour')
GROUP BY proxy_url
HAVING error_pct > 5
ORDER BY error_pct DESC;
```

**Aimsigh seachfhreastalaí mall** (latency p95 > 2s):

```sql
WITH ranked AS (
  SELECT proxy_url, latency_ms,
         PERCENT_RANK() OVER (PARTITION BY proxy_url ORDER BY latency_ms) AS pct
  FROM proxy_logs
  WHERE timestamp > datetime('now', '-24 hour')
)
SELECT proxy_url, latency_ms
FROM ranked
WHERE pct >= 0.95
ORDER BY latency_ms DESC;
```

## Eisiamh Teip Uathoibríoch do Do Sheachvótálaithe Féin

Déanann an linn margadh 1proxy cheana féin díghrádú ar sheachvótálaithe teipthe ina n-aonar (féach [Scór Cáilíochta Seachfhreastalaí](#proxy-quality-scores) ). Le haghaidh seachfhreastalaí** leat** curtha leis an gclárlann, soláthraíonn an sceidealóir sláinte cúlra (`src/lib/proxyHealth/scheduler.ts`) an t-iompar céanna "cuir as an slabhra go huathoibríoch ball marbh", gan aon rud a scriosadh:

```bash
# .env — soft-disable a proxy after 3 consecutive failed probes, re-enable it
# automatically once it starts answering probes again.
PROXY_AUTO_DISABLE=true
PROXY_AUTO_REMOVE_AFTER=3
```

Mar a luíonn sé le slabhra il-seachfhreastalaí:

1. Scrúdaíonn an sceidealóir gach seachfhreastalaí cláraithe gach `PROXY_HEALTH_INTERVAL_MS` (10 nóim réamhshocraithe; 1 nóiméad ar a laghad).
2. Tar éis `PROXY_AUTO_REMOVE_AFTER` as a chéile** dochloíte** teipeanna (teip nasc fíor — teorainn ama nó sprioc an taiscéalaithe féin 5xx ní chomhaireamh riamh, féach [Seachfhreastalaí Seiceáil Sláinte](#proxy-health-checking-v3816) ), tá `status` an seachfhreastalaí socraithe go `dead`.
3. Tá `dead` ar cheann de na stádais a eisiann an scagaire beo-stádais a úsáideann taifeach pool/rotation, agus mar sin stopann rothlú scóip (cruinn-robin / randamach / greamaitheach / latency — féach [Crann Cinnidh Straitéise Rothlaithe](#rotation-strategy-decision-tree) ) láithreach an seachfhreastalaí sin a thabhairt d'iarratais nua. Ní dhéantar difear d'aon seachvótálaithe eile sa linn, agus ní thiteann an linn ar fad go ciúin ar ais go dtí nasc díreach — féach garda dúnta teip- [Chóras Seachfhreastalaí 4-Leibhéil](#4-level-proxy-system).
4. Coinníonn an sceidealóir proxies `dead` proxing ar an eatramh céanna. Filleann an chéad taiscéalaí rathúil eile `status` ar ais go `active` agus athiontrálann sé rothlú — níl gá le hathchur láimhe.

Tá sé seo d'aon ghnó** rogha an diúltaithe agus neamh-millteach** : de réir réamhshocraithe ní dhéanann an sceidealóir ach teipeanna a chomhaireamh agus a logáil (féach polasaí C i `decision.ts`), agus ní scriosann `PROXY_AUTO_DISABLE` as a chéile — arb é is aidhm don bhratach `PROXY_AUTO_REMOVE` ar leith atá níos ionsaithí. Má tá an dá cheann socraithe go `true`, bíonn an bua ag `PROXY_AUTO_REMOVE` (ní bheidh aon úsáid ag seachfhreastalaí atá ar tí a scriosadh le haghaidh bog-dhíchumasaithe eatarthu). Féach an tagairt [Cumraíochta Comhshaoil](../reference/ENVIRONMENT.md) le haghaidh liosta iomlán na n-athróg.
